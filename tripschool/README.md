## 📘 What is PyTrip?

**PyTrip** is the official companion tool for installing and updating  
**TripSchool**, an application designed to help teachers easily organize and manage school trips.

Instead of manually configuring TripSchool, PyTrip automates everything:

- ✔ Downloads the latest TripSchool version
- ✔ Installs required dependencies
- ✔ Configures the environment
- ✔ Provides update management
- ✔ Offers a clean UI for schools and administrators

PyTrip ensures that **TripSchool is deployed correctly on any system**, whether for a classroom, an entire school, or a server.

## 🛠 How It Works

1. Launch the PyTrip installer
2. Choose your installation folder
3. PyTrip downloads the latest version of TripSchool
4. Configuration is applied automatically
5. TripSchool is ready to use 🎉
